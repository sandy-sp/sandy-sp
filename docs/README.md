# Portfolio Docs Workspace

All portfolio project artifacts must stay inside this directory tree:

- `portfolio/docs/` for source notes, planning docs, and task docs
- `portfolio/docs/specs/` for feature specs (spec-driven development)
- `portfolio/docs/tasks/` for executable task breakdowns
- `portfolio/docs/plans/` for implementation plans and milestones

## Working Agreement

This portfolio project follows **spec-driven development**:

1. Write or update a spec first.
2. Derive tasks from the spec.
3. Implement only against approved/current spec.
4. Keep all supporting project documentation in `portfolio/docs/`.
